# WalletPause

让每一次消费都有自己的理由。

## Executive Summary 执行摘要

WalletPause是一款面向大学生的AI消费决策App，将购买记录、预算检查、AI方案对照、冷静期、同伴建议和购买后复盘连接起来，帮助用户形成自己的消费判断。

## Opportunity 商业机会

### Problem & Solution 问题与解决方案

围绕购买前的需求判断、预算取舍与使用预期，提供一条连续的个人决策流程。用户记录商品与理由，查看预算和方案，选择等待或购买，再以实际体验形成可回看的档案。

### Target Market 目标市场

以华南师范大学校园为首批触达场景，优先覆盖有预算或储蓄目标、常为数码与兴趣消费犹豫的成年Android用户。

### Competition 竞争优势

以校园预算为上下文，把AI方案对照、个人旧物和购买后反馈相连；结构化同伴意见保留不同理由，使决定更容易理解与回顾。

## Execution 执行方案

### Marketing & Sales 营销与销售

通过校园课程与兴趣群、同伴转介绍和主题演示获取用户。首轮目标为600次有效触达、120次独立访问、60名安装和36名激活；营销现金预算400元，基准每名激活用户获客成本11.11元。

采用基础功能免费与9.9元／月高级会员订阅。会员提供更多AI分析额度、跨记录复盘、个人报告和多设备备份。

### Operations 产品与运营

- 购买记录与预算：保存使用场景，解释单次支出影响。
- AI方案对照：比较购买、等待、维修、借用或租用。
- 个人旧物匹配：关联已登记物品，发现功能重叠。
- 促销条件拆解：整理满减、凑单、赠品和分期条件。
- 冷静期陪伴：围绕购买动机生成可选检查行动。
- 同伴意见摘要：提炼支持、反对理由与关键分歧。
- 个人决策复盘：对照预期与实际使用，连接相似历史。

技术方案采用Kotlin、Jetpack Compose、Room、文字识别与结构化AI服务。运营跟踪激活、决定完成、七日复用、会员转化和单位服务成本。
